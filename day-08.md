# Day 8 - Linux Basics & CLI Commands

Today, I focused on Linux command-line execution, file patterns, and file types. Here are the key commands and concepts I practiced:

- **File Patterns & Hidden Files:** Learned how Linux manages file types and hidden files (which start with a dot `.`). Used `ls -a` to list all hidden files in the current directory.
- **The `find` Command:** Explored how to search for files based on specific attributes like size (bytes/bits), user owners, and groups.
- **The `locate` Command:** Practiced using `locate` for quick file system searches.
- **The `grep` Command:** Learned how to search for specific words, lines, and patterns inside files.
