## Core Python Fundamentals
- **Python Overview:** Developed by Guido van Rossum; a powerful, versatile language with a massive community and clean, readable syntax.
- **Data Types & Variables:**
  - **Strings:** Text data (`strings = "text"`)
  - **Integers:** Whole numbers (`integer = 89`)
  - **Booleans:** True/False values (`boolean = True`)
  - **Floats:** Decimal values (`float = 9.0`)
  - **Lists:** Ordered collections of items (`list = ["text", 98]`)
  - **Dictionaries:** Key-value pair collections (`dictionary = {"key": "value"}`)
- **Control Flow & Loops:**
  - **For Loops:** Clean iteration syntax (`for i in range(start, stop, step)`)
  - **Conditionals (`if-else`):** Decision-making blocks in programs (e.g., checking values and branching logic).
- **Functions:** Reusable blocks of code defined with `def function_name(parameters):` that can be invoked anywhere to execute specific logic.
