# Day 23: Python Automation — CSV, Requests & Error Handling

## Overview
Focused on building robust Python scripts using file handling, the built-in CSV module, external HTTP requests, and exception handling for CTI automation.

## Key Concepts Learned
- **Requests Module:** Built for handling HTTP operations. Used to fetch live data from URLs, including status codes, response content, and server headers.
- **CSV Module:** Built for processing and formatting tabular data to easily write structured output files (e.g., storing scan results or endpoints).
- **Try-Except Error Handling:** Used to catch and handle runtime errors (such as network timeouts or unreachable servers) gracefully, preventing program crashes.
