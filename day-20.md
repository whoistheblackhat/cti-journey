# Day 20: SIEM Concepts, Log Types & Windows Event Monitoring

## Overview
Studied SIEM (Security Information and Event Management) fundamentals, log classification, and native Windows telemetry mechanisms using TryHackMe resources.

## Key Learnings & Concepts

- **SIEM Definition & Role:** A centralized system for handling security events, log management, and threat detection.
- **Log Categorization:**
  - **Host-Centric Logs:** Generated by endpoints, web applications, and local file executions.
  - **Network-Centric Logs:** Generated by network appliances, VPNs, and routing/perimeter services.
- **Windows Monitoring & Telemetry:**
  - **Sysmon (System Monitor):** An advanced driver/service from Microsoft used to capture deep kernel-level endpoint telemetry (process creation, network connections).
  - **Windows Event Viewer:** The native tool to inspect structured XML and readable event logs. Every action (such as user creation, login attempts, and group modifications) maps to specific **Event IDs** that track timestamps, user/group types, and source IPs for effective attack detection.
