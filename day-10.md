# Day 10: CTI Journey & OverTheWire

Today's focus was on secure communication protocols, OpenSSL, and file comparison utilities.

## 1. OpenSSL & Secure Connections (`openssl s_client`)
* Learned how to use the **`openssl s_client`** command to establish a secure SSL/TLS connection to a remote server/port.
* **Key Concepts:**
  * **SSL/TLS:** Secure Sockets Layer (predecessor to Transport Layer Security - TLS) adds robust encryption and security to network traffic.
  * **Handshake Process:** Used during the initial connection setup to verify/identify websites and exchange cryptographic keys securely.

## 2. File Comparison (`diff`)
* Explored the **`diff`** command, which compares two files line by line and reports the differences between their contents.
