# Day 26-27: CTI Automation — Building `urlhaus-fetcher.py` with CLI Arguments

## Overview
Developed a robust Python automation script to fetch live threat intelligence feeds from the URLhaus API, parse JSON payloads, filter malicious URL indicators, and export structured data into CSV reports using command-line arguments.

## Key Technical Components
- **`requests` Module:** Handles secure HTTP GET communications with the URLhaus API endpoints (`/v1/urls/recent/`) using custom headers (`Auth-Key`, `User-Agent`).
- **`csv` Module:** Programmatically formats and writes structured intelligence rows (`SERVICE_URL`, `STATUS_URL`, `HOST`, `DATE`) with proper UTF-8 encoding and newline handling.
- **`argparse` Module:** Implements a professional Command Line Interface (CLI), allowing dynamic configuration of output filenames via flags (e.g., `-o custom_feed.csv`).
- **Error Handling & Resilience:** Integrated `try-except` blocks to handle network connectivity exceptions (`RequestException`) and API status errors gracefully.
